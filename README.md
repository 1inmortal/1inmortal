## Enfoque de trabajo

- **Rendimiento medible:** documentar el hardware, la ruta de datos y las condiciones de prueba.
- **Tolerancia a fallos:** considerar latencia, pérdida de paquetes y recursos limitados desde el diseño.
- **Claridad de estado:** distinguir prototipos, trabajo en progreso y resultados verificados.
- **Mantenimiento:** separar responsabilidades, automatizar comprobaciones y documentar decisiones.
- **Colaboración:** cambios pequeños y revisables, con enlaces a código y evidencia.
