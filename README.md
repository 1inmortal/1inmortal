### Exploraciones técnicas de 2026

Estas ideas se han trabajado como investigación, planificación o diseño; no las presento como productos terminados.

- **PSP-3000 y homebrew:** preparación de un flujo de trabajo seguro por USB en Windows para una consola con custom firmware.
- **ESP32 + nRF24L01+:** diseño de un dispositivo experimental de recepción y análisis pasivo de actividad en 2.4 GHz, con comunicación SPI y pantalla.
- **Visión por computadora con drones:** pruebas y diseño de interfaces para visualizar detecciones y evidencias de video capturado desde distintas áreas.

## Cómo trabajo

- **Diseño funcional:** jerarquía visual, navegación clara y soporte para distintos tamaños de pantalla.
- **Calidad verificable:** pruebas, lint y automatización cuando el proyecto lo permite.
- **Seguridad práctica:** revisión de dependencias, validación de entradas y cuidado de secretos.
- **Documentación útil:** instrucciones para entender, ejecutar y mantener cada proyecto.
- **Colaboración:** cambios pequeños, revisables y con propósito claro.
